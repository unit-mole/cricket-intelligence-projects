# IPL Championship Intelligence & Prediction

A leakage-safe, calibrated IPL forecasting and tournament-intelligence application built around the **V2 production champion** selected after four controlled model iterations.

## Production champion

Strict out-of-time evaluation, 2025–2026 (142 matches):

- Accuracy: **54.23%**
- Balanced accuracy: **55.00%**
- F1: **52.55%**
- ROC-AUC: **0.5713**
- Log loss: **0.68585**
- Brier score: **0.24636**
- ECE: **0.08786**

The application includes calibrated pre-match prediction, optional post-toss inference, team/player intelligence, model-derived local sensitivity, historical evaluation, experiment governance, and neutral-schedule Monte Carlo championship simulation.

This is a probabilistic analytics project, not betting advice.
